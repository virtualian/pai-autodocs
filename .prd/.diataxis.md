| Role | Priority | Directory | Description |
|------|----------|-----------|-------------|

## Content Principles

- **Users section:** Convey the agentic soul of PAI — it's an agent that magnifies you, remembers you, learns from you, and has real capabilities. Lead with outcomes and what PAI does for them. No code, no directory structures. Make readers feel what it's like to have a personal AI that already knows them.
- **Power Users section:** Configuration-focused. Show what to change, not how the internals work. Emphasise the SYSTEM/USER two-tier model that keeps customisations safe across upgrades.
- **Developers section:** Technical detail appropriate. Extension model (skills, hooks, agents), source code patterns, hook payloads, system architecture.
- **Contributors section:** Project-level concerns. Architecture deep-dives, algorithm design philosophy, memory system internals, upgrade paths.
