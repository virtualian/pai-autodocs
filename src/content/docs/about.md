## What is PAI?

**PAI (Personal AI Infrastructure)** is an open-source system created by [**Daniel Miessler**](https://github.com/danielmiessler) that magnifies human capabilities through AI. It provides a complete framework for building, customising, and extending your own AI assistant — including memory, skills, hooks, agents, and the Algorithm that drives everything.

The official PAI source lives at **[github.com/danielmiessler/Personal_AI_Infrastructure](https://github.com/danielmiessler/Personal_AI_Infrastructure)**.

## What is PAI Auto-Docs?

This site is an **unofficial, AI-generated documentation companion** for PAI. It exists to make PAI more accessible by providing structured, role-based documentation organised using the [Diataxis framework](https://diataxis.fr/).

### Key facts

- **PAI is by Daniel Miessler.** He is the creator, architect, and maintainer of the PAI system. This site documents his work.
- **These docs are AI-generated.** Content is generated by [Claude](https://claude.ai) from the official PAI source files.
- **This is not the official PAI project.** For the authoritative source, always refer to [Daniel's repository](https://github.com/danielmiessler/Personal_AI_Infrastructure).
- **Community-maintained.** This site is maintained by [@virtualian](https://github.com/virtualian) as a community contribution to the PAI ecosystem.

## How it works

PAI Auto-Docs uses an automated pipeline to stay in sync with the official PAI repository:

1. **Daily detection** — A GitHub Actions workflow checks the PAI repo for new commits every day at 6am UTC
2. **Incremental regeneration** — When changes are detected, only the affected documentation pages are regenerated using the Claude Batch API
3. **Source mapping** — A `source-map.json` file tracks which PAI source files feed into which documentation pages
4. **Automatic deployment** — Updated pages are committed, versioned, and deployed to Vercel automatically
