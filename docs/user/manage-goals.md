Your [Telos](/user/telos/) is not static. Goals shift, projects complete, new priorities emerge. This guide covers the ongoing maintenance that keeps PAI's understanding of you accurate.

## Update your goals

When priorities change, tell PAI:

```
My top priority has shifted. I'm now focused on [new priority].
```

```
Add a new goal: prepare for the funding round in Q3.
```

```
Remove the blog series from my goals — I'm deprioritising it.
```

PAI updates your `TELOS/GOALS.md` file. The change takes effect immediately — the next conversation reflects your updated priorities.

## Track project progress

As projects move forward:

```
The beta launched yesterday. Update my projects.
```

```
We hired the senior engineer. Mark that as complete.
```

```
The migration is blocked on the vendor integration. Update the status.
```

PAI keeps `TELOS/PROJECTS.md` current. When you ask "what should I focus on today?" the answer reflects actual project status, not stale context.

## Add new projects

```
I'm starting a new project: building an internal dashboard for the sales team. Target completion is end of Q2.
```

```
New project: evaluate three CRM tools and make a recommendation by next Friday.
```

## Review your Telos

Periodically check what PAI knows about you:

```
Show me my Telos dashboard
```

```
What do you understand about my current goals and projects?
```

```
Review my Telos and flag anything that seems outdated
```

PAI displays a summary of all your Telos files. Review it, correct anything that is stale, and add anything that is missing.

## Evolve your beliefs and strategies

As you learn and grow, your frameworks change:

```
I've changed my mind about [previous belief]. My updated thinking is [new belief].
```

```
Add a new mental model I've been using: [framework name and description]
```

```
I used to prioritise speed over quality. I'm shifting to quality-first for this phase.
```

## Record challenges

When you hit obstacles:

```
I'm stuck on [challenge]. Add this to my challenges.
```

```
The main blocker right now is [description].
```

PAI stores these in `TELOS/CHALLENGES.md`. When it makes suggestions, it accounts for known blockers rather than proposing plans that run into them.

## Capture ideas

For things you are exploring but not yet committed to:

```
I've been thinking about [idea]. Add it to my ideas.
```

```
Interesting opportunity: [description]. Capture it for later.
```

## Tips

- **Update after milestones.** Completed a project? Hit a goal? Tell PAI. Stale context degrades every conversation.
- **Be honest about deprioritisation.** Removing a goal is not failure. It keeps PAI focused on what actually matters to you right now.
- **Review monthly.** A quick "show me my Telos" once a month catches drift before it accumulates.
