PAI can create visual content across a range of formats — from AI-generated illustrations to structured diagrams and data visualisations. You describe what you need, and PAI selects the right approach.

## Generate images

For illustrations, header images, and creative visuals:

```
Create a header image for my blog post about distributed systems
Generate an illustration that shows the concept of compound interest
I need a professional-looking image for a presentation about AI trends
```

PAI selects the appropriate image generation model and style based on your description.

## Create diagrams and flowcharts

For technical diagrams, process flows, and system architecture:

```
Create a diagram showing how data flows through our system
Draw a flowchart of our deployment process
Diagram the relationship between our microservices
```

PAI generates these as Mermaid diagrams, SVGs, or other appropriate formats depending on complexity.

## Build infographics

For data-driven visual summaries:

```
Create an infographic comparing three pricing plans
Visualise the key metrics from our quarterly results
Build a visual summary of our product roadmap
```

## Architecture and system diagrams

For technical audiences:

```
Diagram our system architecture showing the API gateway, services, and database layer
Create a sequence diagram for the authentication flow
Draw an entity-relationship diagram for our data model
```

## Tips

- **Describe the purpose, not just the content.** "An image for a blog post about AI" is okay. "A professional header image for a technical blog targeting senior engineers" is better, because PAI can match the tone and style.
- **Specify the audience.** Diagrams for executives look different from diagrams for engineers. Tell PAI who will see it.
- **Iterate on visuals.** After the first version, refine: "Make it more minimal," "Use our brand colours," "Add labels to the arrows."
- **Combine with content.** "Research our competitors, then create a comparison infographic" chains research into visual output.
