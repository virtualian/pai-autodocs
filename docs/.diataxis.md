## Content Principles

- **Users section:** Outcome-focused. No code, no directory structures, no TypeScript. Explain what PAI does for them.
- **Power Users section:** Configuration-focused. Show what to change, not how the internals work.
- **Developers section:** Technical detail appropriate. Source code, hook payloads, system architecture.
- **Contributors section:** Project-level concerns. Upgrade paths, design philosophy, contribution guides.
